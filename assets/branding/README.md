# VTeam icon

The original purple V logo is restored at the user's request. The unchanged source is `../vteam.png`, which was the web favicon before the volleyball redesigns.

The primary app icon (1024 px), browser fallback (64 px), Apple touch icon (180 px), and web manifest icons (192 and 512 px) are resized copies of that original artwork. `app.json` points the web favicon directly to the original source. No new artwork or redesign is introduced.

The web release updates the browser and install icons. The native primary icon takes effect in a subsequent native build. Existing Android adaptive layers and splash artwork are unchanged.
