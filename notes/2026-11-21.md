Three under-the-hood PRs, no visible change: date labels now come from cached formatters (cheaper Events first paint), and the 694-line Events feed hook is split into small modules on a new `useQueries` helper.

## Shipped

**Under the hood**

- **Date labels through cached formatters.** A new `utils/dateFormat.ts` keeps one formatter per locale and options instead of building one on every `toLocale*String` call; all 55 call sites in 33 files now use it, with byte-identical output (tested in four time zones), and a new test fails on any new per-call formatter. Time spent formatting dates before the first card fell from 67–95 ms to 27–43 ms on a slow phone/desktop profile; the end-to-end first-visit timing didn't move beyond noise. Closes #342 (#344)
- **`useQueries` in `lib/query`; the feed reads its months through it.** A query hook for a list of keys that can change length, sharing cache, dedupe and stale rules with `useQuery`. It replaces the feed's fixed row of 24 `useQuery` slots and removes the app's only `rules-of-hooks` disable plus two `exhaustive-deps` disables. Startup reads unchanged. Part 1 of #343 (#345)
- **Feed hook in pieces.** `hooks/useMonthEvents.ts` (694 lines) moved unchanged into `hooks/feed/` (`state`, `startup`, `fetch`, `fallback`, `previews`, `useMonthEvents`, `useFeedRsvp`), every file under 200 lines; the only edit is that three module-level variables now live on one `feedState` object. Saved device data keys unchanged, so no snapshot `VERSION` bump; cold open stays under 1 s on every tab. Closes #343 (#346)

Screenshots: every screen compared before → after (phone and desktop), no visual changes. The only differences are the random team shuffle on `event-people-balanced` and the "Updated N s ago" stamp on `admin-metrics-live`, which also differ between two captures of the same build. No schema changes.
